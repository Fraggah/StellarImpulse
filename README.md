**Stellar Flow** is a neon-inspired endless runner developed in **Unreal Engine 5** using **Blueprints**.

Pilot a spaceship through an endless procedural track by instantly switching between five lanes using the **Q, W, E, R, and T** keys. Dodge obstacles, collect **Flux Orbs**, and survive as long as possible while the game's speed continuously increases.

The collected Flux energy can be activated to temporarily slow down the world, helping players navigate particularly challenging obstacle patterns. Each run is procedurally generated, encouraging replayability and the pursuit of a higher score.

## Features

- 🚀 Five-lane arcade movement inspired by an inverse Guitar Hero mechanic.
- ♾️ Endless procedural generation using reusable chunks.
- ⚡ Flux system that temporarily slows the world.
- ❤️ Health system instead of instant death.
- 📈 Progressive difficulty inspired by classic Tetris level progression.
- 🎨 Neon/Synthwave visual style with post-processing effects.
- 🏆 Local High Score saving.
- ⚙️ Graphics settings menu (Resolution, Anti-Aliasing, Depth of Field, Fullscreen).

Developed as an academic project for **Unreal Engine 5**.
